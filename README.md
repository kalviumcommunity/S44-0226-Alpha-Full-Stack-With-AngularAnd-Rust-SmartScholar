# Smart Scholar

Smart Scholar is a role-driven scholarship management and approval system built using Angular and Rust.

## Problem Statement

Many institutions manage scholarship applications manually, which leads to delays, lack of transparency, and tracking issues. Smart Scholar digitizes the complete scholarship workflow from application submission to fund disbursement.

## Tech Stack

- Frontend: Angular
- Backend: Rust
- Database: PostgreSQL
- Authentication: JWT
- Deployment: Docker

## Features

- Secure user authentication
- Role-based access control
- Scholarship application submission
- Multi-level approval workflow
- Fund disbursement tracking
- Audit logging system
